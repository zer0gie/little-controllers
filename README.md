## Little Сontrollers

<img src="https://github.com/user-attachments/assets/8a842a3e-c695-464f-9e0a-7cc12fb2d7ed" width="800">

Проект представляет собой прототип с базовой игровой логикой: персонаж свободно перемещается по ограниченной территории, взаимодействует с объектами и реагирует на события вроде урона, бонусов или получения заметок, логгируя их в JSON. 
Управление поддерживает как классические устройства ввода, так и сенсорные, включая возможность переключения в рантайме. 
Всё реализовано с нуля, без внешних зависимостей, с акцентом на чистую архитектуру и универсальность.

**Нажмите `G`, чтобы открыть дневник заметок**

***

The project is a prototype with basic game logic: the character moves freely around a limited area, interacts with objects and reacts to events like damage, bonuses or receiving notes by logging them in JSON. 

Controls support both classic input devices and touch devices, including the ability to switch in rantime. 

Everything is implemented from scratch, without external dependencies, with a focus on clean architecture and versatility.



**Press `G` to open the notes diary**
